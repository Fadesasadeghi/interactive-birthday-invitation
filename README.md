# Interactive Birthday Invitation 🎂

A responsive and interactive birthday invitation built with vanilla HTML, CSS, and JavaScript.

The experience begins with a closed illustrated envelope. Opening it reveals the invitation in multiple interactive steps, followed by a responsive birthday details screen with background music.

## ✨ Features

- Interactive closed → open → details invitation flow
- Smooth screen transitions
- Responsive desktop and mobile layouts
- Persian RTL birthday details
- Browser Back button integration using the History API
- Background music with Play/Pause control
- Music starts only after user interaction
- Reduced-motion accessibility support
- Keyboard-accessible interactive elements
- Local custom font
- Privacy-safe fictional demo content

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript
- History API
- Native HTML audio

## 🚀 Run Locally

Clone the repository:

    git clone <repository-url>

Enter the project directory:

    cd interactive-birthday-invitation

Start a local server:

    python3 -m http.server 8765

Then open this address in your browser:

    http://localhost:8765

## 🎵 Audio

## 🔒 Privacy

This is a privacy-safe portfolio version of the project.

It uses fictional demo artwork and generic event information. No real child photo, guest name, venue, or private event information is included.

## ♿ Accessibility

The project includes keyboard-accessible controls, reduced-motion support, semantic HTML, and accessible labels for interactive elements.

## 📱 Responsive Design

The invitation adapts to desktop and portrait mobile screens while preserving the interactive envelope experience and event details layout.
